# Newspaper
# 📰 Times of India News Layout

A simple newspaper-style webpage created using HTML and CSS. This project demonstrates the use of CSS Multi-Column Layout to display news articles in a newspaper format.

## 📌 Features

- Newspaper-style layout
- Three-column content using CSS
- Scrolling breaking news with `<marquee>`
- Simple and clean design
- Easy to understand HTML & CSS

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📂 Project Structure

```
Times-Of-India/
│── index.html
│── README.md
```

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.

## 📚 Concepts Used

- CSS Multi-Column Layout (`column-count`)
- `column-gap`
- `column-rule`
- Background Color
- Headings and Paragraphs
- Marquee Animation

## 📸 Output

The webpage displays:
- **TIMES OF INDIA** heading
- Scrolling "Last Updated News" banner
- News articles arranged in three columns
- Simple newspaper-style design
